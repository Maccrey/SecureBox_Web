# Business 상시 암호화 보관함·PC 원격 잠금 계약

> 최신 확정 정책(2026-10-29). **분실 후 암호화 실행을 기본 전략으로 사용하지 않는다.** 이 문서는 구현 예정 기능의 설계 계약이다.

## 사용자 흐름
1. 승인된 Business 사용자가 SecureBox 접근 가능 영역에서 계약서·업무 파일을 보호 보관함에 가져온다. 앱은 파일을 AEAD로 암호화·검증한 후 저장한다.
2. 정상 이용 중에는 모바일 생체 인증 + 온라인 관리자 정책에 따른 짧은 세션에서 필요한 문서만 열람한다. 장기간 유효한 평문 복호화 키는 모바일에 저장하지 않는다.
3. 분실 시 **등록 Windows/macOS PC**의 보호된 별도 서명 키와 MFA로 LOCK 명령을 전송한다. 서버는 조직/구독/기기/서명/nonce/만료를 검증해 **VAULT_LOCKED** 상태로 전환하고 신규 복호화 키 접근을 거부한다.
4. 모바일이 오프라인이어도 보관함 암호문은 그대로 유지된다. FCM/APNs는 캐시 정리 보조 알림이며 실행을 보장하지 않는다.
5. **PC_UNLOCK_APPROVED**는 등록 PC 서명 + MFA + **기업 관리자 승인**이 동시에 유효할 때만 허용한다. 휴대폰 자체에서는 분실 잠금을 풀 수 없다.

## 보안·운영 제한
- 명령 ID·nonce 재사용 거부와 트랜잭션 기반 멱등성 필수.
- 기존에 발급된 짧은 키, 이미 열린 평문, 외부 복사본·클라우드 사본은 즉시 회수할 수 없다.
- 신규 키 발급은 서버가 기본 거부하며 오프라인 상태에서 새 복호화를 허용하지 않는다.
- 일반 iOS·Android 앱은 사용자가 선택하지 않은 다른 앱 폴더를 강제로 암호화하거나 스마트폰 전체를 잠글 수 없다.
- 원본 논리적 삭제는 보관함 암호화 및 복구 검증·사용자 동의 후 별도 선택으로 처리하며 완전 삭제는 보장하지 않는다.
- 정상 모바일 열람과 **PC 전용 분실 잠금 해제**는 별도 개념이다.
