# SecureBox 만화 이미지 정책

- `*.webp` 삽화에는 문장, 대사, 제목, 자막, UI 레이블을 포함하지 않는다. 보안의 근거는 삽화가 아니라 HTML의 `comic-copy`, `comic-bubble`, `comic-caveat` 요소다.
- 2026-10-28 제작된 6컷 시나리오 일러스트의 개별 장면에서 1~5편과 7편을 분할했고, 6편은 분실 모바일·PC 보호·암호화 보관함 장면만 사용했다.
- 삽화는 컨셉 시연이며 실제 화면·상용 기능 출시를 의미하지 않는다.
- 화면 낭독기를 위해 HTML img의 alt 속성과 실제 텍스트 컨테이너를 함께 제공한다.
- 이미지 안에 글자가 들어간 기존 마케팅 삽화는 재사용 금지. 이미지 변경 시 리뷰에서 문자 포함 여부를 육안 확인한다.
